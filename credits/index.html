项目说明

关于这个网站，以及让它成为可能的作品。

设计与代码

网站基于 Once UI 团队的 Magic Portfolio 改编， 使用 Once UI 组件。 在原作之上调整了博客归档、摄影排版、背景与交互，并加入本地内容工作室和静态发布功能。

素描背景与博客结构参考 Anthony Fu； 格点鼠标轨迹参考 Astro Bento Portfolio； 摄影标题的字体呈现参考 Horizon。 模板示例摄影来自 Lorant，通过 Magic Portfolio 提供。
